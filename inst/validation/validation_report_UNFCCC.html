1 Purpose and inputs

This report compares the families listed in the selected sheet of CRT_vs_F2F.xlsx with the UNFCCC CRT 2026 extract. Each workbook row becomes one section, in workbook order: a CRT-versus-FADN2Footprint scatterplot, a country-year relative-error heatmap, then an agreement-metric heatmap. Livestock categories and soil pathways are faceted within their selected family. Emission totals and derived intensities remain separate subgroups, with the same three-plot order.

The workbook controls report selection and ordering, not scientific formulas or source mappings. Existing catalogue identifiers are used for matching; the direct and indirect soil families are expanded to their existing pathway identifiers. Use selected_path to override the workbook beside this report. Unselected measures remain in the full comparison exports for traceability.

Per-tonne-meat intensities use public Eurostat slaughtered-meat production from dataset apro_mt_pann, retrieved for the selected countries and years when the report is rendered.

When params$use_mock == TRUE, the script prepares the published mock EU FADN data, using the same constructor, practice inference and GHG routines as real farm data. Mock results are only a workflow demonstration, not scientific validation. All farm types are retained to cover the requested livestock and crop categories. The package has currently been validated only for types 15 and 45; estimates for other types are untested. Set farm_types: [15, 45] to restrict to that validated scope, but then the estimates are not whole-sector totals.

Render from the repository root:

quarto render inst/validation/validation_report_UNFCCC.qmd

To build or refresh the Eurostat population data, run Rscript inst/scripts/EUROSTAT_livestock_pop.R from the repository root. It downloads public Eurostat tables in memory and writes data/EUROSTAT_livestock_pop.rda; it does not access data_raw/. Rebuild any dataset created before the JSON-stat dimension-order correction.

For real data, set use_mock: false, fadn_raw_object_path to the object returned by data_4FADN2Footprint(), and fadn_object_path to the object returned by compute_footprint_ghg(). Both accept .rds, .RData or .rda; an RData file must contain exactly one FADN2Footprint object. Use objects built from the same input dataset. No confidential raw files are loaded in the default mock mode. years and farm_types apply to both objects; set either to null to retain all observations. Use crt_path to override the default AI_agents/outputs/crt_variables_long.csv.

quarto render inst/validation/validation_report_UNFCCC.qmd -P use_mock:false -P fadn_raw_object_path:"C:\data_raw\FADN_EU_17_21_obj.RData" -P fadn_object_path:"C:\data_raw\FADN_EU_17_21_obj_GHGE.RData"

CSV exports contain only national aggregates, coverage counts and diagnostics. By default they are written beside the rendered report; use output_dir to choose a different directory. Do not commit confidential or real-data exports.

2 Inventory data and matching

The long extract is built from UNFCCC CRT 2026 submissions. Matching uses the sheet, variable label and category code/label, not Excel coordinates. Canonical parent rows take precedence over uncoded labels, and parent and child values are never added together. Conflicting repeated values are flagged ambiguous, rather than arbitrarily selected.

Notation keys (IE, NO, NE, etc.) remain non-numeric. IE means included elsewhere, not zero. Missing values and incompatible units prevent numerical differences; unverified unit checks remain visible in the output.

h_unfccc_add_intensity <- function(
    data,
    suffix,
    unit_suffix,
    basis,
    denominator_source
) {
    kt_to_kg <- 1e6
    data |>
        mutate(
            metric_id = paste0(metric_id, suffix),
            unit = sub(
                "/year$",
                unit_suffix,
                sub("^kt ", "kg ", unit)
            ),
            f2f_value = if_else(
                is.finite(intensity_denominator_f2f) &
                    intensity_denominator_f2f > 0,
                f2f_value * kt_to_kg / intensity_denominator_f2f,
                NA_real_
            ),
            f2f_rescaled = if_else(
                is.finite(intensity_denominator_reference) &
                    intensity_denominator_reference > 0,
                f2f_rescaled * kt_to_kg / intensity_denominator_reference,
                NA_real_
            ),
            crt_value = if_else(
                is.finite(intensity_denominator_reference) &
                    intensity_denominator_reference > 0,
                crt_value * kt_to_kg / intensity_denominator_reference,
                NA_real_
            ),

            comparison_basis = basis,
            intensity_denominator_source = denominator_source,

                f2f_status != "ok" ~ f2f_status,
                is.finite(intensity_denominator_f2f) &
                    intensity_denominator_f2f > 0 ~ "ok",
                TRUE ~ "missing_intensity_denominator"
            ),
            crt_status = case_when(
                crt_status != "ok" ~ crt_status,
                is.finite(intensity_denominator_reference) &
                    intensity_denominator_reference > 0 ~ "ok",
                TRUE ~ "missing_intensity_denominator"
            ),
            comparison_status = case_when(
                f2f_status != "ok" ~ f2f_status,
                crt_status != "ok" ~ crt_status,
                !is.finite(comparison_value) ~ "missing_intensity_value",
                TRUE ~ "ok"
            ),
            difference = if_else(
                comparison_status == "ok",
                comparison_value - crt_value,
                NA_real_
            ),
            relative_difference = h_unfccc_ratio(difference, crt_value),
            ratio = h_unfccc_ratio(
                if_else(comparison_status == "ok", comparison_value, NA_real_),
                crt_value
            )
        )
}

2.4 Coverage and diagnostics

Farm-level quantities are expanded once with the FADN sampling weight SYS02; livestock numbers are heads, not livestock units. Gross energy intake is weighted by heads times SYS02, then converted from MJ/head/year to MJ/head/day using the package’s 365-day convention. Cattle totals include dairy and non-dairy cattle, while each subgroup is also shown separately.

CH4 and N2O are recovered from package CO2-equivalent outputs using the package’s own GWP values, not hard-coded inventory factors. Gas emissions are in kt gas/year; Table 3 totals are in kt CO2-eq/year; nitrogen is in t N/year; production is t/year; area is ha.

Interpretation limits:

  • Organic fertilizer activity and N2O emissions are compared at the combined 3.D.1.b category. Origin-specific subdivisions are excluded because the package does not distinguish them.
  • Package manure volatilisation includes NH3 and NOx, not N2. That value is shown as a proxy, with no numerical equivalence statistics.
  • Summing indirect-soil activity pathways can count the same N input twice; the combined activity is marked as a proxy, not a unique total nitrogen input.
  • Grazing deposits are approximated by organic fertilization of grassland.
  • Direct soil emissions omit drained organic soils and soil organic matter mineralisation in the current package.
  • Table 3 manure livestock totals include CH4 and direct N2O; indirect N2O is reported separately under 3.B.5, avoiding double counting.
  • Cropland includes package arable and fallow areas (including permanent crops), not forest/other land. Inventory land definitions and FADN coverage differ.
  • Wheat combines common and durum wheat; maize is grain maize, not forage maize. Table 3.F production can have narrower coverage where residues are not burned.
  • Package factors themselves use inventory reference data: this is a descriptive comparison, not independent validation.
  • If the manure routine reports a missing EF3 for a positive allocation, its affected comparisons carry model_error and the exact error text. No factor is guessed, and no partial manure total is reported. Other model errors stop the report. This is an existing limitation for combined solid-storage/dry-lot systems in the current reference data.
  • When CRT population values are unavailable, livestock rescaling uses EUROSTAT_livestock_pop only if it is available as a direct package-namespace binding; the coverage chart separately loads the package dataset and does not enable the fallback. The builder averages the reported Eurostat population periods within each year; total cattle, dairy cows, pigs, sheep and goats use Eurostat’s live-animal categories, with non-dairy cattle calculated as total cattle minus dairy cows. Poultry is not covered by this fallback. The Eurostat reference value and source are retained in the comparison export. If the fallback is unavailable or a category is missing, affected rescaled comparisons remain unavailable.

3 Agreement metrics and intensities

For each variable/category, matched country-years are summarized with equal weight, using UNFCCC as the reference. Different variables and units are never pooled. All totals other than area and livestock population use coverage-rescaled F2F estimates \(\hat{y}_i\) for country-year \(i\) and UNFCCC reference \(y_i\). Livestock totals use the matching CRT/F2F population ratio; soil and crop totals use the CRT/F2F combined cropland-plus-grassland area ratio. Indirect manure contributions are rescaled separately by species before summing for comparison with CRT 3.B.5; they are not included in the species-level manure totals. Only area and population coverage comparisons use raw totals. Gross energy intake is an explicitly unchanged per-head exception (MJ/head/day), not a total to rescale.

Emission totals are also reported as intensities. Managed-soil emissions are divided by combined cropland and grassland area. Livestock emissions are divided by matching livestock population, and by annual Eurostat slaughtered-meat production for cattle, pigs, sheep and poultry; dairy and non-dairy cattle are not split for meat intensity because Eurostat does not provide separate meat totals for those groups. Raw FADN per-head values use FADN-weighted heads; rescaled FADN and CRT values use the same CRT population reference, with the documented Eurostat fallback where CRT population is unavailable. Per-tonne values use the same Eurostat country-year meat production denominator for both emission sources. Each intensity has its own unit and comparison basis.

  • Mean Percentage Error (MPE): \(\frac{100}{n} \cdot \sum_i{\frac{\hat{y}_i-y_i}{y_i}}\). Positive values indicate overestimation; negative values indicate underestimation. Errors of opposite signs can cancel.
  • Mean Absolute Percentage Error (MAPE): \(\frac{100}{n} \cdot \sum_i{\frac{|\hat{y}_i-y_i|}{y_i}}\). Lower values indicate smaller percentage errors.
  • Coefficient of Determination (R²): \(1-\frac{\sum_i (y_i - \hat{y}_i)^2}{\sum_i (y_i-\overline{y})^2}\), where each difference is squared before summing. A value of 1 indicates perfect agreement; 0 matches the reference-mean predictor; negative values indicate worse agreement than that predictor. This is not squared correlation.
Metric Question Reading
MAPE How large is the percentage error across country-years? < 20% good, 20–50% acceptable, > 50% poor
MPE Does the package over- or underestimate on average? > 0 over, < 0 under; t-test p-value > 0.05 means no detected systematic bias
R² How close are the estimates to the UNFCCC values? 1 perfect, > 0.5 satisfactory, < 0 worse than the UNFCCC mean

Only finite pairs with both statuses ok are included. Zero UNFCCC references are excluded from MPE/MAPE but retained for R². In the percentage formulas, \(n\) is the number of valid pairs with nonzero references (n_percentage_pairs); the reference mean for R² uses all valid pairs (n_pairs). MAPE follows the formula above with the absolute value only in the numerator; it assumes positive references for interpretation as a nonnegative error. R² is NA when fewer than two valid pairs remain or the UNFCCC reference is constant. MPE/MAPE are NA when no nonzero reference pairs remain. Counts and status columns make these cases explicit. MPE/MAPE are stored in percentage units (10 means 10%), while R² is dimensionless. The summaries are exported to UNFCCC_comparison_metrics.csv.

The MPE test is a two-sided one-sample t-test of individual country-year percentage errors against zero, not a test on the single summarized MPE. Its unadjusted p-value and 95% confidence interval (percentage units) are exported with the test statistic, degrees of freedom and test status. Fewer than two errors, nonfinite errors or essentially constant errors (including agreement within machine precision after rescaling) make the test unavailable; no p-value is invented. A p-value above 0.05 is not proof of unbiasedness. Repeated years for a country may not be independent, and testing many variables increases the chance of false positives; these tests are exploratory.

Summary heatmaps show the aggregate metrics and apply the thresholds above. MPE tile colours reflect its t-test, while its signed value indicates the direction of the error. Undefined values/tests are grey. Each page contains at most 12 variables, with valid pair counts beside their names. Every plot caption identifies the estimate basis. Missing scaling factors never fall back to raw totals. Raw values are retained in CSV exports for traceability, but differences and metrics use comparison_value and comparison_basis.

5 Coverage rescaling and interpretation

Raw SYS02-expanded estimates are retained for traceability only, except for the area and livestock population coverage comparisons used to calculate ratios. Coverage rescaling is mandatory for all other totals, including their differences, MAPE, MPE, t-tests and R². Soil/crop quantities use one combined cropland-plus-grassland area ratio per country-year, not a separate ratio for each land-use row. Gross energy averages remain unchanged and are labelled as a per-head exception.

Species-level manure totals include CH4 and direct N2O only, matching the CRT species-category boundary. The separate indirect manure N2O comparison uses quantities split by species, multiplied by each species’ CRT/F2F population ratio, and then summed for comparison with the combined CRT 3.B.5 total. Cattle is counted once, not again through its dairy/non-dairy subgroups. The population catalogue covers cattle, swine, sheep and poultry; if any contributing species lacks a valid population ratio, the entire indirect total is unavailable. This boundary adjustment applies only to the UNFCCC comparison; all manure pathways remain in the full farm footprint. Proxy quantities remain excluded. Zero, missing, non-equivalent or invalid-status denominators do not generate factors; unavailable rescaled comparisons are recorded in diagnostics.

These adjustments are not validation: matching the denominator can remove a coverage discrepancy by construction, and a single area ratio assumes representative land use and practices.
